**Script:** `pipe_clustered/clean_acereason.py`

## Purpose

AceReason-1.1-SFT (nvidia): math+code SFT data whose responses were generated by DeepSeek-R1 and decontaminated against benchmarks. The transform keeps the math category only and strips the `<think>...</think>` block from each response.

Created: 2025-06 · Domain: math reasoning SFT (DeepSeek-R1 distilled) _(date source: AceReason paper, arXiv:2506.13284)_

## Before (raw storage)

- Source: HF `nvidia/AceReason-1.1-SFT` (split `train`)
- Storage: HF dataset (arrow table) in the prefetched local cache

Fields read by the transform (types derived from the actual files):

| field | type | meaning |
|---|---|---|
| `input` | UTF-8 text (arrow `string`) | the problem -> instruction |
| `output` | UTF-8 text (arrow `string`) | response with a <think> block (stripped) |
| `category` | UTF-8 text (arrow `string`) | filter: only 'math' rows kept |

## After (transformed)

- Location: `data_clustered/acereason/all.parquet` (under `/mnt/hdd2/datasets_text_transformed/HRM-Text`; 1 file(s))
- Storage: parquet; columns `instruction`, `response`, `condition`
- Rows: 2,668,741

| column | type | meaning |
|---|---|---|
| `instruction` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | the prompt |
| `response` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | the target |
| `condition` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | comma-separated tags (see keyword table below) |

| `math` | 20,143 | math problem | KEPT (the code rows are dropped) |
