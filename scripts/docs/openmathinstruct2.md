# openmathinstruct2

↑ [index](README.md) · ← [ampsmathematica](ampsmathematica.md) · [next → openthoughts2](openthoughts2.md)

**Script:** `pipe_clustered/clean_openmathinstruct2.py`

## Purpose

OpenMathInstruct-2 (nvidia): 14M problem-solution pairs generated by Llama3.1-405B from GSM8K/MATH training problems (solution augmentation + problem augmentation; answers for augmented problems are majority-voted). Every row goes to cot.parquet; rows not from the original datasets also go to direct.parquet.

Created: 2024-10 · Domain: synthetic math instruction _(date source: OpenMathInstruct-2 paper, arXiv:2410.01559)_

## Before (raw storage)

- Source: HF `nvidia/OpenMathInstruct-2` (split `train`)
- Storage: HF dataset (arrow table) in the prefetched local cache

Fields read by the transform (types derived from the actual files):

| field | type | meaning |
|---|---|---|
| `problem` | UTF-8 text (arrow `string`) | the problem -> instruction |
| `generated_solution` | UTF-8 text (arrow `string`) | model-generated solution (cot.parquet response) |
| `expected_answer` | UTF-8 text (arrow `string`) | short answer (direct.parquet response) |
| `problem_source` | UTF-8 text (arrow `string`) | filter: rows from 'math'/'gsm8k' are excluded from direct.parquet |

## After (transformed)

- Location: `data_clustered/openmathinstruct2/cot.parquet`, `data_clustered/openmathinstruct2/direct.parquet` (under `/mnt/hdd2/datasets_text_transformed/HRM-Text`; 2 file(s))
- Storage: parquet; columns `instruction`, `response`, `condition`
- Rows: 25,023,023

| column | type | meaning |
|---|---|---|
| `instruction` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | the prompt |
| `response` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | the target |
| `condition` | parquet BYTE_ARRAY (logical String) → arrow `string` — UTF-8 text | comma-separated tags (see keyword table below) |

## Keyword: `condition` (output)

Every output record carries this tag; training samples/mixes by it.

| value | rows | meaning | why it matters |
|---|---|---|---|
| `synth,cot` | 13,972,791 | cot.parquet: full generated solution | very large synthetic math reasoning corpus |
| `synth,direct` | 11,050,232 | direct.parquet: short expected answer (augmented problems only) | answer-only variant; original-problem answers are already covered by gsm8k/math_train |

_exact counts (condition is constant per file; rows summed from parquet metadata)_

## Keyword: `problem_source` (input)

Provenance per row; decides direct.parquet membership.

| value | rows | meaning | why it matters |
|---|---|---|---|
| `augmented_math` | 19,173 | new problem derived from MATH | goes to both cot and direct |
| `math` | 5,233 | original MATH train problem | cot only — excluded from direct.parquet |
| `augmented_gsm8k` | 4,612 | new problem derived from GSM8K | goes to both cot and direct |
| `gsm8k` | 982 | original GSM8K train problem | cot only — excluded from direct.parquet |

_estimated from the first 30,000 of 13,972,791 rows_
